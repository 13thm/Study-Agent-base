大模型时代的智能体工程

大模型（Large Language Model）本质上是一个"下一个 Token 预测器"。它不理解世界，
只是在海量文本上学到了词与词之间的统计规律。正因为如此，它会产生幻觉：当训练数据
里缺少某个事实时，它依然会自信地生成一个看起来合理的答案。

智能体（Agent）的出现，是为了给大模型装上手和脚。一个 Agent 至少包含三个部分：
规划（Planning）、记忆（Memory）、工具调用（Tool Use）。规划决定"下一步做什么"，
记忆决定"我知道什么"，工具决定"我能改变什么"。

检索增强生成（RAG）是最常用的落地手段。它的思路很朴素：既然模型记不住私有知识，
那就在回答之前先去知识库里检索相关片段，把片段塞进上下文，让模型"看着资料回答"。
这样一来，幻觉率显著下降，答案也有了可追溯的来源。

工具调用是 Agent 的另一条腿。通过 Function Calling，模型可以输出结构化的调用意图，
由外层程序真正去执行，再把执行结果回填给模型。这里最大的工程难点不是调用本身，
而是异常处理：工具会超时、会失败、会返回超长的结果，Agent 必须优雅地应对这一切。
